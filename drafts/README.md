# Drafts

The side panel's Save draft button writes one file here per player and session, for example `2026-10-05-alex.md` (a second game that day gets `-2`).
Each draft holds that session's numbers, the hands the player showed, and your notes on them.

Drafts are never read by VAMOS and never change a profile.
Merge what is useful into the player's file in `profiles/` yourself, then delete the draft.
