# Drafts

The side panel's Save draft button writes one file here per player and game, for example `2026-10-05-alex.md` (a second game that day, or another player of the same name, gets `-2`).
Each draft holds that session's numbers, the hands the player showed, and your notes on them.

VAMOS reads only a draft's frontmatter, to find the same game and player's draft again, and never changes a profile.
Saving again in the same game replaces that draft (even past midnight or after the player's ID changes), so make your edits in `profiles/`, not here.
Merge what is useful into the player's file in `profiles/` yourself, then delete the draft.
